# Mini3DEngine

Projet Android expérimental réalisé en Kotlin autour de la 3D et du rendu graphique.

## À propos du projet
Ce projet a été développé pour apprendre le fonctionnement de la 3D sur Android, le rendu d’objets, les caméras et les scènes interactives.

Le projet utilise plusieurs bibliothèques externes, notamment Sceneform, afin de mieux comprendre le fonctionnement du rendu 3D et de l’intégration graphique sur mobile.

## Technologies utilisées
- Kotlin
- Android SDK
- Sceneform
- Gradle Kotlin DSL

## Fonctionnalités
- rendu d’objets 3D
- affichage de scènes 3D sur Android
- expérimentation autour des moteurs graphiques mobiles
- gestion de modèles 3D via des librairies spécialisées

## Objectif
L’objectif principal du projet était d’apprendre :
- les bases de la 3D
- le développement Android en Kotlin
- l’utilisation de bibliothèques graphiques
- la structure d’une application mobile plus complexe

## Note
Ce projet est principalement un projet d’apprentissage et d’expérimentation technique.
